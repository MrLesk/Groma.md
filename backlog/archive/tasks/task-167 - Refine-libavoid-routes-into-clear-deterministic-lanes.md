## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Load the current semantic world through the same model boundary used by Groma Web, preserve production flow order, and open only the established 18% route space.

2. Build movable semantic units inside each system or container: one unit per exact authored group, one per ungrouped component, and one complete subtree per container. Generate legal partner-adjacent moves without changing root actor/system/external geography, building sizes, containment, or group identity.

3. Rank legal moves by lifted relationship distance, then evaluate only the top three with the real libavoid router and lane refiner. Accept only a whole-map Pareto improvement: zero building crossings, route artifacts, and shared path remain zero; obstacle clearance and minimum lane gap do not fall; crowded body, under-spaced segments, proper crossings, conflicts, and tiny segments do not increase; at least one improves.

4. Snap only subpixel router nudges on a first or last body run back to the fixed guard axis before refinement, preventing invisible reverse stubs from becoming shared-path artifacts.

5. Reuse the winning candidate’s raw and refined routes. Charge candidate evaluation to placement and report selected final routing separately. Keep production-derived styling, roof/floor labels, Raw/Refined switching, and the isolated :4141 boundary.

6. Prove whole-group and container-subtree movement, deterministic bounded generation, defensive acceptance, and subpixel attachment with fixtures; verify the live map, repeated route hashes, browser interaction and artifacts, repository checks, and human approval.
