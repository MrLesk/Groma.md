## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
When an evaluator selects Wayflow, ngraph renderers, Draw2D, and HTMLGraph in the disposable Revision 04 library comparison, each candidate receives the same approved seven-component Groma scene and is exercised through its own documented public APIs. These candidates survived official-documentation screening, so each requires a live browser harness; a failure is valid only when the harness reproduces a runtime/browser error or exposes a decisive public-API limitation. The result updates the existing 131-candidate comparison without selecting a winner or changing the production viewer.
