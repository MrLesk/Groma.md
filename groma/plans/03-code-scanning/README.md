# Revision 03 — Code scanning

## Outcome

Groma scans one deliberately supported source shape and writes observed components
using the same Markdown format already understood by people, agents, and the viewer.
Source changes can therefore materialize planned architecture in the live view.

## Deliberately absent

- Multiple scanner plugins
- General program understanding
- Automatic plan promotion
- Rename reconciliation
- Confidence scoring
- Fallback extraction
