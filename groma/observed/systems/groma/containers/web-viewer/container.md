# Web viewer

Shows the architecture in a browser as an isometric blueprint: the core-composed sheet inside a proportional drafting band with the editable project title plate, painted as SVG and zoomed and panned through browser controls, with one selection shared with the hierarchy and details panes. `groma web` starts it and pushes every new project or architecture world to the open page.
