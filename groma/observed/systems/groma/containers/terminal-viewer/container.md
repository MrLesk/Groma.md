# Terminal viewer

Shows architecture in fixed terminal chrome with a persistent hierarchy, a pan-only map, reserved details, and a compact Backlog recap. The root names actors, systems, containers, collapsed groups, and external systems; Enter opens only a container to show its components. Task markers remain visible on the map, while Work focus temporarily gives the side panes and map camera to one task without replacing the architect's saved view. The view host starts it.
